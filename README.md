# Week 4 Assignment: Hands-On Lab - Grades, Eligibility & Smart Decisions

## Files Description
* `welcome.py`: Contains the `welcome()` function that generates personalized greeting sentences for PLP learners.
* `toolbox.py`: Contains a collection of three utility functions (`double`, `is_pass`, and `greet`) for basic arithmetic, comparison, and greeting logic.
* `README.md`: Overview of the assignment structure and file descriptions.

## Reflection
The `greet` function was the most interesting to write because it required handling a default parameter value (`greeting="Hello"`). Remembering to structure string concatenation with correct punctuation and spacing ensured the formatting matched the expected output for both default and custom inputs.
